# Skill: Notion-Corporate Design System (Cavere)
Esta skill instrui o agente a adotar a identidade visual do Notion adaptada para um painel corporativo robusto e minimalista.

## Diretrizes Visuais (Estilo Notion + Enterprise):
1. **Fundo e Superfícies:**
   - Fundo geral: Branco puro ou cinza extremamente sutil (`#fbfbfa` / `#f7f7f5`).
   - Cards e Containers: Fundo branco (`#ffffff`), sem sombras exageradas, substituídas por bordas finas e discretas (`border: 1px solid #e1e1df`) e cantos levemente arredondados (`border-radius: 8px`).

2. **Tipografia e Cabeçalhos:**
   - Fontes: Segoe UI, Inter ou sans-serif limpa.
   - Textos principais em cinza chumbo escuro (`#373530`), nunca preto puro, garantindo leitura confortável.
   - Títulos limpos, sem tarjas coloridas pesadas. O foco é o conteúdo estruturado em blocos.

3. **Tabelas e Modadores (Estilo Base de Dados do Notion):**
   - Tabelas estilo banco de dados: Linhas limpas, divisores finos, sem cores berrantes.
   - Badges de Status sutiles: Pílulas minimalistas inspiradas nas propriedades de *Select* do Notion (ex: fundo cinza claro com texto escuro para itens neutros, verde suave para disponíveis, âmbar para em operação).

4. **Botões e Interações:**
   - Botões retangulares limpos com cantos de 6px a 8px (evitar botões totalmente redondos/pills exagerados).
   - Efeitos de hover suaves (`background-color: rgba(0, 0, 0, 0.03)`).
